# Быстрый старт

## Хочу просто запустить и посмотреть

На любом компьютере с Node.js 20+:

```bash
npm install
npm run build
npm run serve
```

Откройте <http://127.0.0.1:4173>. Это рабочая версия интерфейса: редактор,
чат, рой, память проекта, палитра команд, все анимации.

В браузере файловая система виртуальная (хранится в localStorage). Чтобы
получить настоящий терминал:

```bash
npm run bridge          # в отдельном окне
npm run dev             # Vite проксирует /api на мост
```

## Хочу собрать установщик для Windows

Нужен компьютер с Windows, на нём:

1. **Node.js 20+** — <https://nodejs.org>
2. **Rust с MSVC**:
   ```powershell
   winget install Rustlang.Rustup
   rustup default stable-msvc
   ```
3. **Visual Studio Build Tools** с компонентом «Разработка классических
   приложений на C++» (нужен линкер MSVC).

Дальше одна команда:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

Скрипт сам:

- поставит зависимости;
- скачает Vulkan-рантайм llama.cpp (~150 МБ) в `src-tauri\bin`;
- сгенерирует иконки приложения;
- проверит типы и соберёт фронтенд;
- соберёт NSIS-установщик;
- положит его в `release\InfinityCoder-3.0.0-Setup.exe`.

Полезные флаги:

| Флаг | Что делает |
|------|-----------|
| `-SkipRuntime` | не качать llama-server (соберётся только облачный режим) |
| `-SkipIcons` | не генерировать иконки |
| `-SkipModel` | не предлагать скачать модель при установке |
| `-Version 3.1.0` | задать другую версию |

Сборка занимает 10–20 минут (из них ~8 — компиляция Rust в release).
Требуется свободно ~6 ГБ на диске.

Нет Rust? Соберите через GitHub Actions: репозиторий уже содержит готовый
workflow, который сделает то же самое и отдаст `.exe` артефактом.

## Как пользоваться

1. Откройте проект — кнопка папки слева сверху (или «Выбрать папку»).
2. «Настройки» → «Модель» → вставьте свой API-ключ.
   Ключ в сборку не входит, хранится только у вас.
3. Напишите задачу в чат и нажмите Enter.

Горячие клавиши:

| Клавиши | Что делает |
|---------|-----------|
| `Ctrl+K` | палитра команд |
| `Ctrl+P` | переход к файлу |
| `Ctrl+S` | сохранить |
| `Enter` | отправить агенту |
| `Shift+Enter` | перенос строки |
| `Esc` | остановить агента |

## Если что-то пошло не так

**Агент не отвечает, «Провайдер недоступен»**
Проверьте ключ и базовый URL в «Настройки → Модель». Справа внизу диалога
показан текущий статус соединения.

**«Модель загружается дольше 4 минут»**
Локальная модель весит ~5 ГБ и скачивается при установке. Проверьте, что файл
`%APPDATA%\com.miron.infinitycoder\models\qwen-coder.gguf` скачался целиком.

**Агент не может ничего изменить**
Откройте «Настройки → Движок → Подтверждения» и поставьте «Никогда» либо
отвечайте на запросы подтверждения в чате.

**Порт 8080 занят**
«Настройки → Модель → Локально» → поменяйте порт. Он же пропишется в базовый
URL.

**Сборка падает на `npm run build`**
Сначала `npm install`. Если ругается на память — в Windows выполните
`set NODE_OPTIONS=--max-old-space-size=4096`.
